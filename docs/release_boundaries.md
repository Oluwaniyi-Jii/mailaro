# First Release Boundaries

This document defines the strict boundaries for the first shippable version of Mailaro.

## Included in V1 (Core Product)
- **Google Login**: Setup and Gmail permissions for the user.
- **Chrome Extension**: Tracking switch inside the Gmail compose window.
- **Tracked Sends**: Ability to track or untrack an outgoing Gmail message.
- **Open Tracking**: Inserting an invisible pixel to track email opens per recipient.
- **Link Tracking**: Rewriting outgoing links to track clicks.
- **Notifications**: Browser and email notifications for first open and click events.
- **Activity Dashboard**: A web dashboard displaying email sent, opens, clicks, and a timeline.

The primary goal of the first release is to prove that a user can send a tracked Gmail message and reliably see opens, clicks, and notifications.
